# Paradise Nursery 🌿

## Project Name

**Paradise Nursery - Online Plant Shopping Cart**

## Project Description

Paradise Nursery is a dynamic React-based e-commerce web application for an online plant shop.

The application allows users to browse different categories of houseplants, view plant information, add plants to a shopping cart, and manage the quantities of products in the cart.

## Features

* Paradise Nursery landing page
* Home, Plants and Cart navigation
* Three plant categories
* 18 unique plants
* Plant thumbnail images
* Plant names and descriptions
* Plant prices
* Add to Cart functionality
* Disabled Add to Cart button after adding
* Dynamic shopping cart item count
* Increase product quantity
* Decrease product quantity
* Delete products from cart
* Individual product total
* Overall cart total
* Checkout Coming Soon message
* Continue Shopping functionality
* Responsive design

## Redux

Redux Toolkit is used to manage the shopping cart state.

The cart supports:

* Adding products
* Increasing quantity
* Decreasing quantity
* Removing products
* Calculating cart totals

## How to Run

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go to the project directory:

```bash
cd paradise-nursery
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the local URL displayed by Vite in your browser.
